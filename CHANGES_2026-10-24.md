# Changes of 2026-10-24

Base: `c01a633` (Audit fixes for the percentage-only bar...). Everything below is new in this branch.

## New features

### Session window and Solo / Party view
- **Session window** (menu "…" > Session window): time, EXP, EXP/hr, mesos, mesos/hr, levels, deaths, map, party size. **Reset Session** clears only these counters; the tracker, the log and the shared runs are untouched.
- **Solo / Party view** (new button in the top bar, left of the log button): rows **Solo**, **Party**, **Total**, with time, EXP, the share of the EXP (out of 100%) and the mesos. When several party sizes were played, each size is listed underneath. It can be **docked** (a panel in the main window, under the tracker, while the log keeps the whole right side) or **popped out** into a floating window that follows the main window. The choice is remembered (`party_view` in the settings).
- `session_stats.py` (new): the numbers behind both windows, with no screen or tkinter in it so it can be tested.

### CSV session log
- `session_log.csv` in the data folder (UTF-8 with BOM, opens in Excel): events `start`, `pause`, `map`, `party`, `level_up`, `death`, `reset_session`, and a `summary` every 5 minutes of tracking. Rotated to `.old.csv` past 5 MB. A failed write never stops tracking. Menu: "Open session log (CSV)".

### Your EXP vs the party's bonus
- `exp_messages.py` (new) reads the game's message lines **without OCR**: the game draws them in one fixed pixel font, so each glyph (digits, `+`, brackets) and each label ("You received EXP", "Bonus EXP for PARTY", "You have gained mesos") is compared with the exact shape. Anything that doesn't match is skipped, never guessed. The text is see-through, so it is picked out with a local-contrast mask (plus a yellow mask for the bonus line).
- `LineTracker` tells new lines from lines that only scrolled up or flickered (same text at the same place, or a whole number of lines higher).
- A gain on the EXP bar is split into **You** and **Party bonus** only when the lines add up to it exactly (oldest lines first, a few leftover lines may be skipped). The rest stays **Not split**. The Solo / Party table shows these rows.
- A dedicated thread reads the message area at the data rate, because the lines scroll away in a few seconds.
- `split_debug.log` in the data folder records what the reader saw and how gains were matched (useful when the split looks wrong).
- Menu: "Collect EXP message samples" saves pictures of the message area into `samples/` (used to build the glyph shapes).

### Mesos from the message lines
- After the inventory has set a start (or, without one, from the first message line), mesos are counted from "You have gained mesos (+N)". The next look at the inventory corrects whatever the lines missed, and never counts anything twice. Not counted while a shop, storage or trade window is open.
- Note: the inventory still has to be readable once (not covered by this overlay) to set the start and to correct drift.

### Reading speed settings
- **Settings > Speed**: *Data collection rate* (default **7 Hz**, 1 to 20) for how often the screen is read, and *Display refresh rate* (default **1 Hz**, 1 to 20) for how often the numbers on screen are redrawn. Changes apply at once. Keys: `rate_hz`, `ui_hz`.

### EXP log
- Two new columns: **EXP** and **Mesos** (the totals of each line), next to the per-hour columns.
- **Details window** (right-click a line > Details..., or double-click): totals, per-hour and per-5-minute rates, mesos coverage, potion cost and net mesos, a row per party size for merged lines, how the line compares with all your logs on the same map (average, best, solo vs party), and the line's note. A **pace chart** shows EXP/hr of each 5-minute stretch.
- Each 5-minute stretch now also keeps counters on its log line: **kills**, **your EXP / party bonus EXP**, **mesos drops and amounts**, **deaths**, **levels gained**, the EXP the level needs and what is left. The Details window turns them into kills/hr, EXP per kill, drops/hr, mesos per drop, the party bonus share, deaths/hr, level progress per hour and time to the next level. These counters are not part of a line's seal, so lines stay "unedited". Older lines don't have them and simply show fewer sections.
- `log_details.py` (new): the numbers behind the Details window.

### Other
- `start.bat`: finds Python (`py -3` or `python`), installs `requirements.txt` if the imports fail, warns when Tesseract is missing, and starts the app without a console (`start.bat debug` keeps one).
- New icon for the Solo / Party button (`ui_gfx.py`); the top bar hides it in compact mode (`ui_main.py`).

## Known limits
- The message reader is built for the game window size of the samples (1366x768). Another size reads nothing and everything stays "Not split".
- The digit **4** has not been seen in a sample yet; a line with a 4 is skipped until it is added.
- Faded lines over a bright background are sometimes not read; the EXP bar stays the source of truth, so a gain that can't be explained is just "Not split".
- Mesos need the inventory visible once to set the start. If this overlay covers the inventory's mesos, they can't be read.
